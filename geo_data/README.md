Natural Earth (https://www.naturalearthdata.com), public domain, reduced for geo.py:

- countries_50m.json: ne_50m_admin_0_countries, each country's English name, ISO code and polygons (coordinates
  rounded to 0.001°).
- places_10m.json: ne_10m_populated_places_simple, as [name, country, region, lat, lon, population, is_capital].
